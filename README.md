# Flipbook HTML

Libro con efecto de hojeo (ambas caras de cada página) usando [StPageFlip](https://github.com/Nodlik/StPageFlip), HTML + CSS + JS.

## Estructura
```
flipbook/
├── index.html
├── css/styles.css
├── js/
│   ├── config.js   # cantidad de imágenes, nombres y proporción
│   └── app.js      # lógica del flipbook
├── images/         # page-01.jpg … page-45.jpg
├── .gitignore
└── README.md
```
